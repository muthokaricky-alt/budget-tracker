# Budget Tracker

A clean, simple budget tracking application built with React and Vite. Track your income and expenses with data persistence using localStorage.

## Features

- **Track Transactions** - Add income (positive amounts) and expenses (negative amounts)
- **Real-time Summary** - Automatically updates balance, total income, and total expenses
- **Persistent Storage** - All data is saved in your browser's localStorage
- **Delete Transactions** - Remove individual transactions
- **Clear All Data** - Reset everything with a confirmation prompt
- **Loading States** - Skeleton screens and button loading indicators
- **Responsive Design** - Works on desktop and mobile devices
- **Keyboard Accessible** - Full keyboard navigation support

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and development server
- **CSS Variables** - Design system with consistent theming
- **localStorage** - Client-side data persistence
